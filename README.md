# ooceBot

This repo contains a Twitch bot that I use for my Twitch streams.

# Notes

For storing sensitive information, I have opted to use an app.config approach, meaning that all passwords, API keys, local folder addresses, etc. are stored in an app.config file which I have added to the project's .gitignore file. If you plan to use this project for your own purposes, you are certainly welcome to do so, however, you will need to create your own app.config file to get it to run properly.
